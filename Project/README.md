# Lab project
 
Each student should develop a web page for the project assessment component of this course. 
The project is individual and has two parts: 

1. HTML + CSS + responsive (deadline and evaluation during lab 7, in week 8)  
2. JavaScript (deadline and evaluation during the last lab of the term)

You can choose freely the topic of your website, but you should take into account a list of general requirements (see below).

### Theme examples for your project:
- personal web page  
- presentation website for a book, a writer, a game, a band, a film director, an actor or a film etc.   
- personal blog, travel blog, culinary blog etc.  
- educational content website (tutorials, exploratory explanations,  interactive assignments written in JavaScript)
- presentation website for a bookshop, library, museum, art gallery, NGO etc.   
- presentation website for a touristic landmark or destination
- commercial website  
- a simple game, a multimedia art project

You can ask your lab teacher to help you choose the theme. They can show you some examples ;-) 

*We encourage you to choose a topic that you really enjoy, no matter how silly it might seem at first.*

### Marks breakdown (20 marks):

1. HTML + CSS + responsive:  8 marks  
2. JavaScript: 12 marks

### Minimal general requirements for part 1 (HTML + CSS):

- separate files for HTML and CSS code
- the content of the website should be meaningful (no Lorem ipsum, please)
- no frameworks or libraries allowed (unless approved by the teacher; ask if you would like to use one – scss etc.)

HTML:
- passing the HTML validity tests http://validator.w3.org/
- using the semantics tags discussed during lectures/labs

CSS:
- passing the CSS validity tests https://jigsaw.w3.org/css-validator/
- the website should be responsive (media queries, relative units, different display types)
- using the basic CSS selectors (by id, class, tag, contentElement, childElement, the nth child of a certain type :nth-of-type)
- specifying general properties: width, height, color, background, font-size, border, padding, margin, display etc.
- using columns for the layout of at least one page; not using tables for the layout (use flex and/or grid)
- the website should have a CSS drop-down menu (or otherwise expanding)
- the website should contain a transition that implies changing several properties at different time intervals 
- the website should contain an animation that changes several properties of the same element 
- ! bonus point ! for generating content using :after, :before (this should make sense, don't force it, be creative)  

### Minimal general requirements for part 2 (JavaScript + ajax + misc):
A. JavaScript
- separate file for the JavaScript code
- changing the style of an element or of a group of elements 
- DOM manipulation (selecting by id, tag, class, using CSS selectors)
- creating and deleting HTML elements
- using and changing events triggered by mouse and keyboard actions
- changing properties
- functional inputs (for example: text input/range/number/radio/checkbox, select, textarea)
- using setTimeout or setInterval
- using localStorage (to save in localStorage a collection of elements)
- using at least one method from the classes: Math, Array, String, Date
- randomly changing the values of a property (for example: colour, dimensions, position)
- using the properties classList, target or currentTarget
- using the methods getComputedStyle, stopPropagation
- form data validation using regular expressions

B. AJAX
- Ajax request with data fetching from a json file
- sessions: e.g. login/logout (using Storage / a json file) 

Besides implementing these minimal requirements (whose correct inclusion does not guarantee obtaining full marks) in your projects, consider other aspects such as accessibility, internationalization (translation, special character etc.), using canvas/svg etc. Discuss your ideas with your lab teacher.

*The requirements can be changed/extended by each lab teacher.*
